# Week-1
This project focuses on data acquisition, data cleaning, preprocessing, and exploratory data analysis using Python. A publicly available Mauna Loa Weekly Atmospheric CO₂ dataset was acquired through the Statsmodels dataset interface. The dataset contains weekly atmospheric carbon dioxide measurements collected at the Mauna Loa Observatory over a period spanning several decades. The initial data inspection included checking the dataset dimensions, data types, missing values, duplicate dates, chronological ordering, and descriptive statistics. During the cleaning stage, the CO₂ measurements were explicitly converted to numeric form and the date index was validated and sorted. Missing CO₂ observations were identified and handled using time-based interpolation because the dataset is a regularly sampled time series and neighboring observations provide useful temporal information. Duplicate dates were also checked. Repeated CO₂ values were not incorrectly removed because identical measurements can legitimately occur on different dates. Exploratory Data Analysis was then performed using descriptive statistics and multiple visualizations. The analysis included a missing-value visualization, a complete time-series plot, annual mean CO₂ analysis, a histogram showing the distribution of measurements, and a monthly analysis to examine recurring seasonal patterns. The analysis revealed a substantial long-term increase in atmospheric CO₂ concentration together with recurring seasonal variation. The project also discusses limitations, including the historical time period, single-location nature of the observations, and the assumptions involved in interpolation. The complete methodology, Python code, visualizations, results, and conclusions are provided in the accompanying report and project files.
